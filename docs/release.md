# Release Process

1. Run `pnpm test` and `pnpm build`.
2. Push source to `main`.
3. Create and push a version tag such as `v0.1.0`.
4. GitHub Actions builds Windows x64, macOS x64, macOS arm64, and Linux x64 on
   native runners.
5. The tag job publishes all generated artifacts, `SHA256SUMS.txt`, and the
   Windows `Astraluster.cer` public certificate to the GitHub Release.

Windows signing uses an ephemeral `CN=Astraluster` self-signed code-signing
certificate generated by the GitHub Actions Windows runner. The private key is
not retained after the job. macOS releases are unsigned and unnotarized until
an Apple Developer certificate is available. Linux releases are unsigned.

Local Windows builds can be created with `pnpm dist:win`. The release script
passes `--publish never` to Electron Builder; only the GitHub Actions publish
job is permitted to create a GitHub Release.
