## DSH Transparent UI Plugin

DeepSeek Desktop includes a modified copy of the MIT-licensed
[DSH Transparent UI Plugin](https://github.com/WYH66666666/DSH-Transparent-UI-Plugin)
in `packages/dsh-transparent-ui`.

Copyright (c) 2026 John Wu

The original MIT license is retained at
`packages/dsh-transparent-ui/LICENSE`.

Desktop-specific changes retain the stock-layout compatibility mode, add a
selectable Mica material, remove the upstream Aqua palette and decorative
defaults, and integrate the result with the desktop wallpaper bridge. The
modified plugin's full MIT license is also included in packaged release
notices.
